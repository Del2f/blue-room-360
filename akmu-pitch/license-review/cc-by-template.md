# 향후 CC-BY 에셋 크레딧 템플릿

확인일: 2026-10-25. 현재 감사한 51개 소스 참조 에셋은 Poly Haven이며, 아래 Sketchfab 후보는 취득·사용 확정 목록이 아니다. 구매나 다운로드는 실행하지 않았다.

CC BY 4.0은 상업 이용을 허용하지만 적절한 출처, 라이선스 링크, 수정 여부 표시가 필요하다. 제공된 저작권·라이선스·면책 고지도 보존한다. 실제 모델 페이지의 버전이 3.0 등이면 해당 버전 원문을 적용한다. 출처: https://creativecommons.org/licenses/by/4.0/ (2026-10-25).

```text
[작품명] — [저자 표시명 및 프로필 URL]
Source: [원본 모델 페이지 URL]
License: [정확한 라이선스 이름/버전] ([라이선스 원문 URL])
Changes: [변경 없음 / 색상 변경 / 재질 변경 / 리토폴로지 등 실제 변경]
Acquired: [YYYY-MM-DD, 취득 계정·증빙 위치]
Used in: [F1–F6 / 루프 / 큐브맵 / 웹·SNS]
Required notices: [공급자가 제공한 추가 고지]
```

웹에서는 접근하기 쉬운 Credits 페이지, 영상은 설명란 또는 적절한 크레딧에 배치한다. 클라이언트에게도 해당 표시를 유지할 문구를 전달한다. 라이선서의 공식 후원·승인을 암시하지 않는다. 원본 권리와 초상·상표 등 다른 권리를 함께 확인한다.
